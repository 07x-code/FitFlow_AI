# 项目结构

FitFlow AI 由 React PWA、FastAPI、PostgreSQL、Redis 和大模型服务组成。后端按照 API、应用用例、领域、端口和基础设施分层。

```text
FitFlow_AI/
├── backend/
│   ├── app/
│   │   ├── api/                         # FastAPI 路由、认证依赖和异常响应
│   │   ├── application/
│   │   │   └── use_cases/               # 账号、画像、计划、记忆等应用用例
│   │   ├── domain/
│   │   │   ├── models/                  # 领域模型
│   │   │   └── policies/                # 安全校验与领域规则
│   │   ├── ai/
│   │   │   ├── agents/                  # AI 教练和训练计划 Agent
│   │   │   ├── core/                    # Agent 基础类型与消息模型
│   │   │   ├── tools/                   # 模型可调用的只读工具
│   │   │   ├── orchestration/           # LangGraph 工作流
│   │   │   └── services/                # 计划解释等 AI 服务
│   │   ├── ports/                       # Repository、Session、LLM 和记忆端口
│   │   ├── infrastructure/
│   │   │   ├── auth/                    # Redis 登录会话实现
│   │   │   ├── knowledge/               # 本地健身知识检索
│   │   │   ├── llm/                     # 大模型 Provider
│   │   │   ├── memory/                  # Redis 短期工作记忆
│   │   │   └── persistence/postgres/    # SQLAlchemy 模型与 Repository
│   │   ├── bootstrap/                   # 共享依赖和请求级用例装配
│   │   ├── core/                        # 环境配置
│   │   ├── data/                        # 后端本地数据
│   │   └── main.py                      # FastAPI 应用入口
│   ├── alembic/                         # 数据库迁移
│   ├── tests/                           # 后端测试
│   ├── requirements.txt
│   └── .env.example
├── web/
│   ├── public/                          # PWA 图标与动作媒体
│   ├── scripts/                         # 动作数据构建脚本
│   └── src/
│       ├── api/                         # FastAPI 客户端
│       ├── components/                  # 通用界面组件
│       ├── data/                        # 前端动作索引
│       ├── pages/                       # 登录、教练、计划、动作等页面
│       ├── styles/                      # 页面样式
│       └── utils/                       # 前端工具函数
├── data/                                # 动作数据构建来源
├── docs/                                # 设计和实施文档
├── infra/postgres/init/                 # PostgreSQL 初始化脚本
├── compose.yaml                         # PostgreSQL 与 Redis 本地服务
├── pytest.ini
└── README.md
```

## 后端依赖方向

```text
API
  -> Application Use Case
  -> Domain / AI Agent
  -> Port
  -> Infrastructure
  -> PostgreSQL / Redis / LLM Provider
```

API 层负责 HTTP 输入输出和登录身份解析。应用层组织业务流程，领域层保存规则和数据模型。端口定义应用需要的能力，基础设施层负责数据库、Redis、大模型和本地知识的具体访问。

## 主要请求链路

普通业务请求：

```text
React PWA
  -> FastAPI Router
  -> Request scoped Use Case
  -> Repository
  -> PostgreSQL
```

AI 教练请求：

```text
React PWA
  -> Coach API
  -> Coach Use Case
  -> 用户画像、正式计划、长期记忆、本地知识
  -> Coach Agent
  -> LLM Provider
  -> Response
```

训练计划确认请求：

```text
计划生成
  -> Proposal
  -> 用户修改或确认
  -> 后端安全校验
  -> 正式 Training Plan
  -> PostgreSQL
```

## 数据归属

| 数据 | 存储位置 |
| --- | --- |
| 用户账号和密码哈希 | PostgreSQL `users` |
| 用户训练画像 | PostgreSQL `fitness_profiles` |
| 长期记忆 | PostgreSQL `user_memories` |
| 训练计划提案 | PostgreSQL `training_plan_proposals` |
| 正式训练计划 | PostgreSQL `training_plans` |
| 训练记录 | PostgreSQL `workout_sessions` |
| 登录会话 | Redis |
| 短期工作记忆 | Redis |
